# AVClub PowerShell Module

AVClub is a simple PowerShell module for working with the metadata of audio and video files. The
module allows users to set information for files such as the title, album, artist, description,
composer, year, track number, and much more.

## Installation

This module requires PowerShell 7 and can be installed via the [PowerShell Gallery](https://www.powershellgallery.com/packages/AVClub).

```powershell
Install-Module AVClub
```
